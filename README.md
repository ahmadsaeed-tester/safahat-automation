# Safahat Automation

Playwright end-to-end tests for browsing and searching the Safahat book catalog, reading books online, and downloading a book as a PDF.

Website under test: [https://www.safahat.org](https://www.safahat.org)

## What the test covers

The suite currently has one end-to-end test that runs these flows in sequence:

1. **Browse the catalog** — open Safahat and check that book listings are present.
2. **Search and read online** — search for *الفيزياء الفلكية: مقدمة قصيرة جدًّا*, open the book, and verify that the chapter *الأفكار الكبرى* and its text are visible.
3. **Download a PDF** — search for *الدنيا في باريس*, open its book page, download the PDF, and verify that the downloaded file is non-empty and has a PDF signature.
4. **Filter by author and read online** — search for the astrophysics book, filter by author *جيمس بيني*, open the matching book, and verify readable chapter text.
5. **Filter by topic and open the first result** — search for *أدب*, expand **موضوعات الكتب**, select **أدب**, and open the first book in the category. The test checks the category, book link, and title.

These are sequential steps within one test—not separate independently selectable tests. A site security-verification page is detected and recorded for the affected flow; the steps continue where possible. If any flow was blocked, the overall test is reported as skipped at the end. A skipped run therefore does not mean all assertions passed.

## Requirements

- Node.js and npm
- Chromium browser installed for Playwright

## Setup

```bash
npm install
npx playwright install chromium
```

## Run tests

Run the suite in Chromium:

```bash
npm test
```

The Playwright configuration currently uses a visible browser (`headless: false`). Run with the Playwright headed option explicitly:

```bash
npm run test:headed
```

Run only the end-to-end flow by its title:

```bash
npx playwright test --project=chromium --grep "Safahat end-to-end catalog"
```

In CI, the configuration enables retries and a single worker. Locally it uses Playwright's default worker count and does not retry.

## Reports and artifacts

The Playwright configuration writes:

- **HTML report:** `playwright-report/` — open it with `npx playwright show-report`.
- **Allure results:** `allure-results/` — raw results and attachments generated by test runs.
- **Failure artifacts:** screenshots on failure, videos retained on failure, and traces on the first retry under `test-results/`.
- **PDF downloads:** `downloads/`.

Generate and view the Allure HTML report:

```bash
npm run allure:generate
npm run allure:open
```

To serve the Allure report directly from the results:

```bash
npm run allure:serve
```

Allure results need to be generated by a test run before the report can contain run details. Generating from an empty or stale `allure-results/` directory can produce an empty or outdated report.

## Site access note

Safahat may show a Cloudflare security-verification page to automated browsers. The test does not attempt to bypass that protection. When detected, it records the blocked flow and skips the overall test after completing the remaining possible steps. For a meaningful successful run, use an environment where Safahat permits the browser session, then regenerate the reports.
